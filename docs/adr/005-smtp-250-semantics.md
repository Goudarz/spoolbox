# ADR-005: معنای پاسخ `250`

- وضعیت: **Accepted** (2026-10-24)
- زمینه: اگر `250` پیش از ذخیره کامل فرستاده شود، شکست بعدی یعنی پیام گمشده؛ اگر بخشی از ذخیره (مثل tagها) بعد از commit شکست بخورد و خطا برگردد، کلاینت retry می‌کند و پیام تکراری ساخته می‌شود.
- تصمیم: `250` فقط پس از commit یک تراکنش شامل پیام، envelope، blob، tagهای ingest، outbox و event. هر خطا پیش از commit → `451 4.3.0` و هیچ اثری در DB. parse ناموفق → پیام با `status=parse_failed` ذخیره می‌شود (هرگز گم نمی‌شود).
- پیامدها: کار سنگین (parse کامل، FTS، webhook، relay) پس از commit در JobRunner.
